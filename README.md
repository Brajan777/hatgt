# HATGT - Gorras Retro Guatemala 🇬🇹

Tienda en línea de gorras retro, dad caps, snapbacks y truckers de colección con visor interactivo multi-ángulo, cálculo de costo/inversión y pago contra entrega en toda Guatemala.

## Características

- 🧢 **Catálogo Interactivo**: Visualizador de gorras multi-ángulo (frontal, lateral 45°, broche y bajo-visera).
- 🇬🇹 **Pago Contra Entrega**: Sistema de checkout adaptado a los 22 departamentos de Guatemala con integración a WhatsApp.
- 📦 **Rastreo de Guías**: Módulo de seguimiento simulado para Cargo Expreso / Guatex.
- 📏 **Guía de Tallas Interactiva**: Medidor de circunferencia craneal en centímetros y tallas US.
- 🛒 **Bolsa de Compras**: Carrito lateral con cálculo dinámico para envío gratis (Q300+) y accesorios adicionales.
- ⭐ **Opiniones y Calificaciones**: Sección de reseñas verificadas de clientes chapines.
- 🔐 **Panel de Administración**: Gestión de catálogo, fotos, precios, costos de inversión, métricas financieras y registro de ventas.

## Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```
